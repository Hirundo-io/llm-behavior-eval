## Gaps carried forward as disclosed, unresolved items (not fixed in this freeze)

1. **No model-revision pin** for the base model or the judge model — only the dataset has one (item 1, 2, 8).
2. **No `max_model_len` readback/hard-fail guard** anywhere in this codebase — confirmed absent, not merely undocumented (item 6, 10).
3. **`repetition_penalty` is hard-pinned to `1.0`** for this evaluator family — not a choice among alternatives (item 15).
4. **LoRA adapter has no rank/identity assertion in-repo** — a manual SHA-256 check must be performed before each run (item 3; see `run_smoke.sh`).
5. **`enable_thinking` is a soft, string-sniffed best-effort** — must be verified empirically during the smoke, not assumed (item 5).

None of these gaps were introduced by commits `361842c`/`83a814a`; all predate this freeze and are reported here because the study brief asked for verified, not assumed, plumbing.
